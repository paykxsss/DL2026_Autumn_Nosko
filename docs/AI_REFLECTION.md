# Часть 3. Работа с AI (AI_REFLECTION.md)

## 3.1. Применённые инструменты и промпты
- **Инструменты:** ChatGPT, GitHub Copilot.
- **Примеры промптов:**
  1. *«Напиши endpoint на FastAPI с использованием библиотеки qrcode, который принимает цвет кода, цвет фона и возвращает картинку в формате Base64 Data URL»*.
  2. *«Сделай аккуратную форму настроек на React и Tailwind с цветовыми пикерами, радиокнопками форматов и живым превью»*.
  3. *«Как на чистом JS проверить, является ли введенная строка валидным HTTP/HTTPS URL?»*.

## 3.2. Анализ эффективности
- **Где AI сэкономил время:** Сгенерировал конвертацию изображения из Pillow BytesIO в строку Base64 для моментальной передачи на фронтенд.
- **Где AI ошибся:** В первой версии генерации SVG нейросеть использовала неподдерживаемые аргументы цветов в `SvgPathImage`. Ошибка была исправлена раздельным пайплайном обработки PNG и SVG.
- **Осознанный отказ:** Отказался от хранения QR-кодов в файловой системе сервера, выбрав генерацию Base64 прямо в память — это избавило от мусорных файлов на диске.

## 3.3. Выводы и рекомендации
1. Задачи с генерацией медиа (QR-коды, картинки) идеально ложатся на Python благодаря богатой экосистеме библиотек.
2. AI ускоряет написание шаблонных UI-форм в 3-4 раза.
